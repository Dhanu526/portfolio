# Dhanunjayarao Pujala Portfolio

Professional portfolio website for LinkedIn sharing and resume use.

## Files

- `index.html` - main page content
- `styles.css` - visual design, responsive layout, and animations
- `script.js` - reveal animations and dynamic year

## Run Locally

Because this is a static site, you can run it in two easy ways:

1. Open `index.html` directly in a browser.
2. Or serve it with a local server:

```powershell
python -m http.server 5500
```

Then open `http://localhost:5500`.
